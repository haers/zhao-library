# 小赵资料馆

本目录仅包含公开静态页面、图片及浏览器运行资源。维护源码、账号配置和整理记录不在发布目录内。

[![Netlify部署状态](https://api.netlify.com/api/v1/badges/0d923fb1-f628-4e31-ac2c-847ba63a70cd/deploy-status)](https://zhao-library.netlify.app/)

## Netlify 发布

本公开仓库只保存静态成品；Netlify监听main分支推送后自动部署，不连接维护源码仓库。使用已有成品，不设置安装命令，构建命令为空，发布目录为`.`。Netlify自动识别目录页面及404.html，不配置首页兜底；_headers声明安全与收录响应头。

正式站点：https://zhao-library.netlify.app/。canonical与sitemap已经在构建时生成。

资料内容与分享链接由各自提供方维护，图片来源见站内说明页。
